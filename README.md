# OpenCode Mobile

> **Безопасность:** ограничения путей файловых инструментов **не являются песочницей для shell**. Команды работают с правами приложения, а при включённом root могут повредить систему и данные. Проверяйте действия перед подтверждением. Подробнее: [SECURITY.md](SECURITY.md).

Android-приложение — ИИ-агент для чата, работы с проектами и запуска команд на устройстве. Написано на Kotlin и Jetpack Compose; root не обязателен. Интерфейс вдохновлён desktop-подходом OpenCode, без использования его логотипов и фирменных материалов.

## Установка

Требуются **Android 7.0 / API 24+**, JDK 17 и Android SDK API 35:

```bash
./gradlew :app:assembleDebug
./scripts/install-emulator.sh app/build/outputs/apk/debug/app-debug.apk
```

Либо скачайте `opencode-mobile-debug` из успешного запуска [GitHub Actions](https://github.com/ccndjfgjs/Dustin-Fisher-Murphy/actions/workflows/android.yml), распакуйте архив и установите APK. Debug-пакет `dev.opencode.mobile.debug` может сосуществовать с релизным. Подпись CI debug может меняться между сборками; **удаление приложения стирает его данные**. Инструкции по установке, обновлению и подписи — в [docs/RELEASE.md](docs/RELEASE.md).

[v0.1.0](https://github.com/ccndjfgjs/Dustin-Fisher-Murphy/releases/tag/v0.1.0) — **устаревшая debug-сборка** для Android 8+; не production-релиз.

## Начало работы

1. Выберите рабочую папку. Доступ к общему хранилищу необязателен; без него доступна папка приложения.
2. В **Настройки → Добавить провайдера** настройте адрес, модель и свой API-ключ. Поле поддерживает обычную вставку, кнопку «Вставить из буфера» и показ/скрытие ключа.
3. Выберите модель рядом с полем чата и внимательно проверяйте запросы на выполнение действий. Рассуждения отображаются отдельно, когда API их возвращает; настройки доступны только для известных поддерживаемых моделей.

## Возможности и ограничения

- OpenAI-совместимые Chat Completions и Anthropic Messages, потоковые ответы, остановка, локальная история с поиском и переименованием, экспорт чата в Markdown, выбор модели и копирование текста/кода. Экспорт содержит сообщения, рассуждения, вложения и результаты инструментов: храните его безопасно.
- Если в корне выбранного проекта есть `AGENTS.md`, его текст автоматически отправляется модели с каждым запросом. Кнопка **@** в чате выбирает текстовые UTF-8 файлы проекта; можно также написать `@src/file.kt` или `@"имя с пробелами.txt"`. Отправляются снимки файлов на момент сообщения (не более 5, по 64 КБ и 192 КБ суммарно). Пути и симлинки наружу отклоняются. Не прикрепляйте секреты без необходимости; содержимое хранится в незашифрованной локальной истории.
- Файловые инструменты, терминал и сворачиваемые карточки действий; изменяющие действия и сетевой `web_fetch` требуют подтверждения, если авто-подтверждение не включено.
- API-ключи зашифрованы с Android Keystore, но локальная история сессий **не зашифрована приложением**. Системное резервное копирование отключено.
- Каталог шаблонов не гарантирует доступ к модели, её стоимость или поддержку инструментов. В режиме thinking официального DeepSeek инструменты отключаются. Реальные внешние API не вызываются в автоматических тестах.

## Проверки

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
./gradlew :app:connectedDebugAndroidTest  # запущенный эмулятор или устройство
```

CI запускает тесты, lint, эмуляторы API 24/35 и проверку подписания временным ключом. Проект ещё требует проверки на реальных устройствах, независимого аудита и подготовки к публикации. Условия использования кода пока не определены: см. [LICENSE](LICENSE).
