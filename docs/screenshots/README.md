# Скриншоты интерфейса

Снимки получены из **работающего приложения на эмуляторе Android 15 / API 35**, а не нарисованы или смоделированы. Использованы демонстрационные файлы и локальная сессия без API-ключей и сетевого запроса; на обоих снимках чата показан одинаковый диалог. «До» — состояние `e6a8ed2` до пяти задач; «после» — изменения задачи интерфейса. Снимок терминала «до» сохранён из предыдущего запуска того же эмуляторного сценария; демонстрационные файлы и экран терминала в нём такие же. Файловый экран намеренно существенно не менялся.

Процедура воспроизведения: на изолированном эмуляторе подготовьте в одном каталоге два checkout'а `before` и `after` и запустите `bash after/scripts/screenshots/capture-on-emulator.sh` (требуются JDK 17, Android SDK и adb). Скрипт устанавливает и удаляет **debug-пакеты в этом эмуляторе**, поэтому используйте только отдельный тестовый эмулятор: удаление пакета стирает его данные. Данные снимков синтетические; настоящее устройство и реальные платные API не проверялись.
