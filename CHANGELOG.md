# Журнал изменений

## Не выпущено — черновик описания релиза

### Добавлено

- Вставка API-ключа из буфера, показ/скрытие ключа и подсказка при HTTP 401; выделение и копирование сообщений, кода и вывода терминала.
- Компактная кнопка отправки и остановки; выбор модели и доступных режимов рассуждения рядом с вводом.
- Отдельный потоковый блок рассуждения с копированием и хранением в локальной истории. Для Anthropic сохраняются подписанные и скрытые блоки, необходимые при вызове инструментов.
- Более компактный интерфейс чата в духе desktop IDE, карточки инструментов, предпросмотр запрошенной замены и встроенное подтверждение действий.
- Документация по безопасности, провайдерам, подписи и установке; сравнительные скриншоты эмулятора.

### Важно

- DeepSeek и поддерживаемые Qwen по умолчанию работают без thinking. Если включить thinking на официальном DeepSeek, инструменты отключаются, поскольку приложение не возвращает не-Anthropic рассуждения в запросах.
- OpenAI-совместимые шлюзы могут отличаться; модели и тарифы меняются. Возможность вызова инструментов и реальные платные API нужно дополнительно проверять.
- Ограничения файловых путей не изолируют shell. Root и команды могут повредить данные. Локальная история сессий не зашифрована приложением.
- CI debug-подпись не является постоянной; выпуск APK/AAB требует ключа владельца. Реальные устройства и production-подпись требуют отдельной проверки.
- Лицензия ещё не выбрана владельцем; файл `LICENSE` — заглушка, а не лицензия.

## v0.1.0 — устарел

Старая debug-сборка для Android 8.0+; не является текущим production-релизом. Актуальный проект собирается для Android 7.0+.
